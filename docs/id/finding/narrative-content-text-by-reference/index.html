NarrativeContent holds its text by reference

https://kerfors.github.io/usdm-overlay/id/finding/narrative-content-text-by-reference

NarrativeContent is defined as "The container that holds an instance of unstructured text and which may include objects such as tables, figures, and images." The class has no text attribute. Its text is a NarrativeContentItem, which NarrativeContent references (contentItemId, relationship type Ref, 0..1) and which StudyVersion composes (narrativeContentItems). The section and its text are separate instances, linked by reference.

standing
For discussion: Holding the text in a separate referenced item may be deliberate, for reuse across sections.

Test

SPARQL ASK over usdm_v4.ttl, expected true.

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
PREFIX usdm: <https://w3id.org/cdisc/usdm/v4/>
ASK {
    usdm:NarrativeContent skos:definition ?def .
    FILTER (STRSTARTS(STR(?def), "The container that holds an instance of unstructured text"))
    usdm:NarrativeContent-contentItemId rdfs:domain usdm:NarrativeContent ;
        rdfs:range usdm:NarrativeContentItem ; usdm:relationshipType "Ref" .
    usdm:StudyVersion-narrativeContentItems rdfs:range usdm:NarrativeContentItem ; usdm:relationshipType "Value" .
    FILTER NOT EXISTS {
        ?p rdfs:domain usdm:NarrativeContent ; rdfs:range usdm:NarrativeContentItem ; usdm:relationshipType "Value" .
    }
    FILTER NOT EXISTS {
        ?p rdfs:domain usdm:NarrativeContent ; rdfs:range xsd:string .
        FILTER (?p NOT IN (usdm:NarrativeContent-id, usdm:NarrativeContent-instanceType, usdm:NarrativeContent-name,
                           usdm:NarrativeContent-sectionNumber, usdm:NarrativeContent-sectionTitle))
    }
}
