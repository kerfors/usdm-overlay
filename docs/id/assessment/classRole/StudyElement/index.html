The model holds the three characteristics in the definition as the description (naming) and two TransitionRule parts, transitionStartRule and transitionEndRule, each a text carrier. The only other payload is a reference to study interventions. The derived rule counts the two TransitionRules as parts and assigns Aggregate; read through its parts, the content of the element is text.
A basic building block for time within a clinical study comprising the following characteristics: a description of what happens to the subject during the element; a definition of the start of the element; a rule for ending the element.

Derived role: Aggregate by rule-role-aggregate. The authored role refines it.
