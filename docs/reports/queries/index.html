03_logic_and_classification_as_text.rq

Attributes that hold a condition or a classification as text: candidates for a structured or coded representation.

6 rows.

kind attribute rationale
Classification as text BiomedicalConceptProperty-datatype The value names a datatype for the response value. The published examples use a small set of datatype names, and USDM_CT.xlsx gives no value list. See finding bc-property-datatype-names.
Classification as text IntercurrentEvent-strategy ICH E9(R1) names a fixed set of strategies for intercurrent events, so the substance is a classification. The definition asks for a textual description and USDM_CT.xlsx gives no value list. Classified by substance; the conflict is recorded as finding intercurrent-event-strategy-textual.
Classification as text Organization-identifierScheme Names the organization that issues the identifier. The published examples use a small set of issuer names, and USDM_CT.xlsx gives no value list.
Classification as text Procedure-procedureType The definition calls the value a classification, but USDM_CT.xlsx gives no value list and the range is xsd:string. The same definition pattern is coded elsewhere in the model, see finding procedure-type-uncoded.
Logic as text ConditionAssignment-condition The attribute holds the condition under which the decision instance moves to its target scheduled instance. The range is xsd:string and USDM_CT.xlsx gives no value list. The model has a Condition class, but this attribute does not reference it; the logic is held as text.
Logic as text ScheduleTimeline-entryCondition The definition describes a logical evaluation. The range is xsd:string, USDM_CT.xlsx gives no value list, and the attribute does not reference the Condition class. The logic is held as text.
