## Abstract-class attributes carry a subclass's C-code

<a id="abstract-class-attribute-ccodes"></a>`abstract-class-attribute-ccodes` · Model-stated

For attributes declared on abstract classes, dataStructure.yml carries the C-code, preferred term and definition of one concrete subclass, not the abstract class's own entry in USDM_CT.xlsx. usdm-rdf renders the YAML, so its skos:exactMatch on these properties points to the subclass concept. Example: SyntaxTemplate.text carries C207478 Characteristic Text; USDM_CT.xlsx lists C207578 Syntax Template Text for SyntaxTemplate.text.

**Observed:** 27 of 388 C-coded attributes in dataStructure.yml differ from USDM_CT.xlsx. All differences are on abstract classes (Identifier 1, PopulationDefinition 9, ScheduledInstance 3, StudyDesign 9, SyntaxTemplate 5); 27 C-coded attributes are declared on abstract classes in total. usdm-rdf skos:exactMatch follows the YAML code for all 27.

## Intercurrent event strategy: fixed set, specified as text

<a id="intercurrent-event-strategy-textual"></a>`intercurrent-event-strategy-textual` · Authored

IntercurrentEvent.strategy is defined as a textual description and has no value list. ## Narrative refers to model instances by markup in text

<a id="narrative-references-by-markup"></a>`narrative-references-by-markup` · Example-observed

## Template parameters are matched by name inside text

<a id="template-tags-by-markup"></a>`template-tags-by-markup` · Example-observed

Syntax-template text marks parameters with usdm:tag elements that name a ParameterMap.tag. The stored tag is a bare name; the angle brackets that the NCI definition of ParameterMap.tag describes appear only in the template text. Resolution is by name inside a string, so a tag can lack a matching ParameterMap, and the published examples include such a case.

**Observed:** 16 usdm:tag elements in 13 texts; stored tags containing angle brackets: 0. Unresolved: observational.json EligibilityCriterionItem_2 'max_agexxx'.
